# FABLE ARTS

The website of [FABLE ARTS](https://fable-arts.com), an arts organisation presenting story-driven work from artists around the world.

Plain HTML, CSS and JavaScript with no build step. GitHub Pages serves it from `main`.

`the_parts_we_give_the_game/` holds an early build of [The Parts We Give](https://danielpini.github.io/TPWG/), a video game commissioned for a contemporary opera. The current version lives in its own repository, [TPWG](https://github.com/DanielPini/TPWG).

## Run it

Serve the folder with any static server, for example:

```sh
npx serve .
```
